# vubatype-ui

Next.js frontend for VubaType. This package is `vubatype-ui` in the pnpm workspace at `apps/web`.

Setup, environment, and the full command list are in the [repository README](../../README.md).

From the repository root:

```bash
pnpm install
pnpm --filter vubatype-ui dev
```

The dev server listens on http://localhost:3000. It rewrites `/api` to `API_URL`. The dev script defaults that to `http://127.0.0.1:3001`.
